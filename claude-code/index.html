ABOUTこのスクールについて

「AIが便利らしい」とは聞くけれど、自分の仕事にどう使えばいいのか分からない——。そんなパソコンが専門ではない方が、実際の作業でAIを使いこなせるようになることを目指すスクールです。

01

非エンジニア前提

専門用語は最小限。パソコンの得意・不得意を問わず、はじめての方に合わせて一歩ずつ進めます。

02

実作業が
そのまま教材

講師が毎日おこなっている本物の作業を題材に、「そのまま真似すれば動く」形で学びます。

03

手を動かして
身につける

各回90分のうち約1時間は実践。見て終わりにせず、その日のうちに「作れた」を持ち帰ります。

CURRICULUM学べること（全6回）

講師の実作業を6つのテーマに分け、順番に学びます。

  1. 身近な作業の自動化メール・LINEの文面づくり、エクセルの集計 など
  2. 文章を量産する音声やメモから、記事・メルマガの下書きを一気に作る
  3. スライド＆画像づくり資料スライドやアイキャッチ画像を手早く用意する
  4. SNS運用の自動化X（旧Twitter）などの投稿づくりを仕組み化する
  5. 売る仕組みづくりランディングページ・申込フォーム・自動返信メール
  6. 事務作業の時短集計・カレンダー・領収書整理・定期実行の自動化

VOICE受講生の声

15〜28時間を削減（1〜3日分の作業に相当）

昨日から、LP2件・フライヤー1件・「PPTで作っていたテンプレートをHTMLの入力フォームにする」作業の4点をお願いし、どれくらい時間が削減できたか試算してもらいました。おおよそ15〜28時間、1〜3日分の作業時間に相当するとのこと。Claude Codeを使えるようにしてくださって、本当にありがとうございます！

FAQよくある質問

プログラミングは本当に未経験でも大丈夫ですか？
はい。専門用語はできるだけ使わず、はじめての方に合わせて進めます。パソコンの基本操作（文字入力・コピー＆ペースト）ができれば参加できます。
当日参加できない回があっても大丈夫ですか？
はい。全回アーカイブ（録画）を視聴いただけます。視聴期限はありません。
受講に必要なものはありますか？
インターネットに接続できるパソコンと、Zoomを利用できる環境をご用意ください。使用するAIツールの利用については講座内でご案内します。
